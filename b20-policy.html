🤖 Agent economy — launch tokens programmatically

Allow-listed AI agents can turn a natural-language brief into a ready-to-execute launch plan via /api/b20-ai (mode agent), then deploy custodially (Turnkey) under a daily spend cap. The planner never moves funds — execution stays on the audited deploy path.

curl -X POST https://orlixai.xyz/api/b20-ai \
  -H "X-Orlix-Key: <agent-key>" \
  -H "Content-Type: application/json" \
  -d '{ "mode": "agent", "brief": "Launch an immutable community token for the Base builder meta, cap 1B, ban blocklisted wallets" }'

# → { plan: { token, onchain, advisory, trust }, execute: { endpoint, body } }
# then POST execute.body to /api/b20-skill to deploy.

Requires B20_AGENT_ALLOWLIST + Turnkey signer env. Ask an admin to enable your agent key.
