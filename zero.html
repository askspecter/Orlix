What Zero Does

Inspect repos, edit files, run commands, manage sessions. All from your terminal.

Interactive TUI
Full terminal interface with slash commands, model picker, live plan rendering, scrollback history, and session management.
25+ Providers
OpenAI, Anthropic, Gemini, Groq, DeepSeek, Mistral, xAI, Qwen, Ollama, LM Studio, or any compatible endpoint.
Permission-Gated
File writes stay in workspace. Shell commands, network access, and destructive operations require explicit approval.
Local Sessions
Sessions stored on disk. Search, resume, and fork. Secrets redacted from logs. Zero telemetry uploaded.
Headless Mode
Run zero exec for scripting and CI/CD pipelines. Text, JSON, or stream-JSON I/O.
MCP & Plugins
Extensible through MCP servers, custom skills, plugins, and specialist subagents. Build your own workflow.

Get Started

Install in seconds. Cross-platform. No config needed.

npm / bun
npm install -g @gitlawb/zero
linux / macos
curl -fsSL https://raw.githubusercontent.com/Gitlawb/zero/main/install.sh | bash
from source (requires Go 1.25+)
git clone https://github.com/Gitlawb/zero && cd zero && make install
then run
zero
$ zero --permissions

Safety First

Granular permission controls. You decide what Zero can touch.

Workspace reads allowed by default. File writes limited to workspace unless you grant access.
Shell commands are permission-gated. Destructive commands require explicit approval.
Network access controlled by sandbox policies. No silent data exfiltration.
Secrets redacted from all logs. Sessions stored locally. Zero telemetry uploaded.
